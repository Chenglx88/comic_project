# T1 条文规范（单集生产，默认档）

适用：一集剧本、分镜或提示词包的完整生产；验收可用门禁命令表达。

## 段落

| 段落 | 必填 | 内容 |
|:--|:--:|:--|
| 头行 + 定界符 | 是 | `## ===== <ID> start/end =====` |
| `/goal` | 是 | 一句话目标 + 完成判据 |
| `/context` | 是 | 上游产物路径 + 承重事实（角色锁、主角状态） |
| 写面白名单 | 是 | 本层可写目录，超出即停 |
| QA 档位 | 是 | 本块按 T1 执行 |
| `/workflow` | 是 | 编号步骤，含命令 |
| `/output_format` | 是 | 产物路径 + 压缩判决 JSON |
| `/constraints` | 简短 | 本层禁止事项 |
| 出口自检 | 是 | 1-2 条可失败判据 |

## 写法

```text
## ===== EP01-L4 start =====
/goal
为 EP01 生成 40-60 个单镜提示词，全部通过 prompts 门禁

/context
- 分镜：03_storyboard/EP01/
- 角色锁：04_prompts/_shared/character_lock.json
- 主角：以 protagonist.json 的 selected 为准

写面：04_prompts/EP01/

/workflow
1. 读 shots.csv 与角色锁
2. 计算 character_lock_digest
3. 先写 S001（text2img），再写其余（img2img）
4. 跑 python3 .claude/scripts/validate.py prompts 04_prompts/EP01

/output_format
产物：04_prompts/EP01/S###.json；判决：压缩判决 JSON

/constraints
- 不调用外部 API
- 不改分镜与角色锁
- 未定选不硬编码主角

出口自检（2 条，可失败）
- [ ] validate.py prompts 04_prompts/EP01 → 通过
- [ ] 镜头数与 shots.csv 行数一致
## ===== EP01-L4 end =====
```

## 纪律

- 写面白名单之外的写入 = 停下上报。
- 自检必须可失败；恒过即门禁失效。
- 失败即上报，不进无限修复轮。
- 降档需用户裁决。
