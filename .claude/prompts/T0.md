# T0 条文规范（单镜 / 单句修正）

适用：单文件、单字段、单句台词的修正；验收可用一条命令表达。

## 最小形态（三要素）

```text
## ===== <ID> start =====
/goal
<一句话目标，含步骤>；未达即上报，不进修复轮

写面：<唯一可写路径>

出口自检（1 条，可失败）
- [ ] <可被截停的具体断言>
## ===== <ID> end =====
```

## 裁剪

- 不写 `/context`、工程上下文、批次表、`/init`。
- 只保留写面白名单与 1 条可失败自检。
- 不写 `/constraints` 长篇；硬约束靠代理卡与 CLAUDE.md §5。

## 纪律

- 写面白名单之外的写入 = 停下上报。
- 出口自检必须能真的失败；恒过的自检视为门禁失效。
- 失败即上报，不静默降级、不悄悄改小目标。
- 降档需用户裁决，不得自行把 T1/T2 压成 T0。

## 例

```text
## ===== P-01 start =====
/goal
把 04_prompts/EP01/S003.json 的 duration_sec 从 9 改为 5，并同步分镜表对应行；未达即上报

写面：04_prompts/EP01/S003.json、03_storyboard/EP01/shots.csv

出口自检（1 条，可失败）
- [ ] python3 .claude/scripts/validate.py gate EP01 → 通过
## ===== P-01 end =====
```
