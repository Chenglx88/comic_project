# 图生视频提示词模板

## 结构

```text
[首帧] + [动作] + [运镜] + [时长] + [一致性约束]
```

## 必填

| 字段 | 写什么 |
|:--|:--|
| `first_frame` | 首镜定标后的关键帧路径 |
| `last_frame` | 有明确落幅时填；否则留空 |
| `prompt` | 动作 + 运镜，一个镜头一个主动作 |
| `params.duration_sec` | 与分镜表 `duration_sec` 一致，3-8 秒 |
| `consistency.reference_image` | 指向首镜关键帧，保住脸与服装 |

## 运镜词表

固定、推、拉、摇、移、跟、升降、环绕。禁止「炫酷」「电影感运镜」这类不可执行描述。

## 规则

- 首镜 S001 用文生图定标，不做图生视频。
- 后续镜头一律以首镜关键帧为参考，不重新文生图。
- 动作幅度与镜头时长匹配：4 秒只写一个动作。
- 不在 prompt 里改角色外观；外观由参考图锁定。
