# 世界观圣经

## 核心设定

主角是「被五境共主挑选的试炼者」。每集坠入一个异世界「境」，必须理解该境的规则（= 一个大学专业）才能通关离开。用异世界冒险的壳，装大学专业科普的核。

## 五境

| 境 | 核心隐喻 | 子场景 |
|:--|:--|:--|
| 修仙境 | 规则 / 系统 / 抽象推演 | 漂浮山讲道台、功法训练场、古建楼阁藏经阁、虚空结界 |
| 机枢城 | 工程 / 制造 / 硬件 | 蒸汽齿轮大街、高塔工坊、地下管线层、试飞平台 |
| 万象医馆 | 生命 / 人体 / 救治 | 问诊大堂、手术回廊、药圃后山、解剖密室 |
| 星渊观测所 | 宏观 / 数据 / 未知探索 | 穹顶星盘室、深渊电梯井、数据瀑布厅、边缘哨站 |
| 言灵殿 | 表达 / 文化 / 社会运作 | 万卷书廊、辩论斗技场、交易市集、幻境剧场 |

## 硬规则

1. 每境的「规则」必须能映射到一个专业的一组核心概念，不能只做背景板。
2. 试炼者不能直接使用其它境的能力；跨境界限是剧情张力的来源。
3. 导师以意象化形象出现（如藏经阁老者、工坊总师），不念真实姓名与名单。
4. 每集必须回收上集至少一条悬念，并留下一条新的。
5. Demo 阶段主角不换装，现代校服作为「异乡人」标识；正式版每境一套主题服。

## 视觉配方

每境 4 个子场景 × 随机组合 = 单境 12+ 种画面搭配，统一日系赛璐璐风格。
